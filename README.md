# Kronika Zawodów — KCD2 RP

Interaktywny poradnik profesji do publikacji na GitHub Pages. Pierwszy zawód: **Kowal**.

## Funkcje
- Responsywna strona w stylistyce średniowiecznej
- FAQ z rozwijanymi odpowiedziami i wyszukiwarką
- Opis XP, materiałów, wydobycia, narzędzi, ulepszania stanowisk i napraw
- Miejsce na przyszłe profesje i ilustracje

## Publikacja
W ustawieniach repozytorium wybierz **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Adres po uruchomieniu Pages: https://hogcraft2-cpu.github.io/kronika-zawodow/

## Rozbudowa
Treść, style i działanie strony znajdują się w pliku `index.html`. Następne zawody można dodać jako osobne sekcje, a obrazy w katalogu `assets/`.
